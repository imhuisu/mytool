장비 선택
자동 저장 켜짐  · 숫자칸은 누르면 전체 선택되어 바로 덮어쓸 수 있습니다. 값을 바꾸면 자동 저장됩니다. 초기화는 등록한 세팅과 수정한 기준값까지 전부 지웁니다.
옵션 수치
적용 구분 옵션 0강 기준 현재 목표 증가분
메인·변동 옵션 모두 0강 기준값 × (강화단계+1)로 증가하고, 우수 등급이면 전체에 ×1.25가 붙습니다. 적용 칸의 ✓(초록)이 반영, ✕(회색)이 미반영입니다. 메인 옵션은 항상 적용이라 잠겨 있고, 변동 옵션은 장비마다 붙는 게 다르므로 내 장비에 실제로 붙은 것만 체크하세요. 체크한 것만 요약·단계별 상세·합산에 반영됩니다. 목록에 없는 옵션은 + 옵션 직접 추가로 이름과 0강 기준값을 넣으면 장비별로 저장됩니다.

검증 현황
옵션 하나하나 기준으로 셉니다. 변동 옵션은 장비마다 일부만 붙으므로, 같은 장비를 여러 번 캡처해야 전부 확인됩니다. 옵션표의 ✓ 는 실측 대조를 마친 값, ? 는 제보받은 표 값만 들어 있어 실제와 다를 수 있는 값입니다. 아래 목록의 옵션이 붙은 장비를 얻으면 캡처를 올려 확인해 주세요.
규칙 요약
능력치 = 0강 기준값 × (강화단계 + 1), 우수 등급은 여기에 ×1.25
  → 아드라노스 검 영혼 2% 기준: 0강 2% / +1 4% / +5 12% / +15 32% (우수 +15는 40%)
DP 비용 = 20 × N + 60  (N강에 도달할 때) → +1은 80, +2는 100 … +13은 320
재료 = +1~+6 없음 / +7~+9 스피릿부스트(SB) 4개 / +10 이상 SB 4 + 드래곤스케일(DS) 4
요구 레벨 = 기본 요구레벨 + 50 × N  (반지만 40 × N)
지팡이 업적당 옵션 = 기준값 × (N+1) × 업적 수  · 마법서 레벨당 옵션은 계수 자체가 표시되므로 책 레벨을 곱하지 않습니다
실제 장비 캡처 24종 전수 검증 완료 (2026-09-20) — 대검·칼날 / 원형 방패·방패 / 방어구 / 투구 / 신발 / 반지 / 단검 / 도끼 / 지팡이 / 활 / 마법서, 일반·우수, 0강~13강 전 구간에서 옵션·요구레벨 모두 일치.
예) 우수 아드라노스 지팡이 +13 → 2.1×14×1.25 = 36.75% (게임 36.8) · 보레아스 신발 +1 → 6.8×2 = 13.6% (게임 13.6)
차원 선택
소울순·코인순은 최종 진화형 기준으로 정렬합니다.
소형 적
이름 속성 HP 방어 코인 소울 진화 비용
회색 줄이 묶음 제목, 그 아래 1번이 기본형이고 2번부터가 진화형입니다. 묶음 제목을 누르면 접힙니다. 지역과 드롭은 묶음 제목 줄에 적었습니다 — 진화 여부와 무관하게 같습니다. 여기 적힌 코인·소울은 보너스 적용 전 기본값입니다. 실제로는 승천, 소울 리퍼, 베스티어리 마스터리 등이 곱해져 더 커집니다.
진화 비용은 코인으로 사는 값입니다. 거인은 기본형에도 출현 해금 비용이 붙습니다. 위 버튼으로 어둠의 염가(−50%)와 공포 포용(−25%) 할인을 켜고 끌 수 있습니다 — 두 개는 곱연산이라 둘 다 켜면 정가의 37.5%입니다. 초승천 업그레이드 Generations가 있으면 여기서 더 깎입니다. 밑줄 친 값은 게임에서 직접 확인한 실측가이고, 나머지는 위키 자료입니다. 자료가 없으면 미확인으로 표시됩니다.
거인
이름 속성 HP 방어 코인 소울 진화 비용
방어가 있는 거인은 방어도를 다 깎기 전까지 화살이 관통하지 않습니다. 진화하면 체력과 방어가 크게 늘지만 소울 보상도 몇 배로 뜁니다 — 얼음 페어리 퀸은 체력 450에 소울 380, 각성한 탱크는 방어 150에 소울 640입니다.
원소별 몬스터
괄호 안은 소울 값입니다. 장비의 불·얼음·전기·어둠 유형 영혼 옵션은 여기 적힌 몬스터를 잡을 때만 붙습니다. 원소는 대부분 진화로 생기므로, 해당 진화를 해금하지 않았다면 그 옵션은 사실상 놀고 있는 셈입니다. 물음표 표시는 자료가 엇갈려 확인이 필요한 항목입니다.

처치 속도 · 배율
처치 간격은 소형 적 한 마리 잡는 데 걸리는 시간입니다. 1초면 초당 1마리.
거인 스폰은 적이 뜰 때 거인일 확률입니다 — 기본 2.5%, 오버킬 노드를 찍으면 3.5%. 장비의 거인 출현 옵션이 여기 더해집니다.
검 데미지를 넣으면 적마다 몇 번 마주쳐야 잡히는지를 HP·방어로 계산해서 차원별로 따로 적용합니다. 한 방에 못 죽이면 넉백돼서 다시 만나야 하고, 그 사이 다른 적이 스폰되므로 단단한 적일수록 잡은 마리 수가 줄어듭니다.
실측 사례: 소형 78,000마리 도는 동안 거인 2,000마리(=스폰 2.5%)를 잡던 사람이 전기 성체 예티(HP 200·방어 50)로 진화한 뒤 248마리로 떨어졌습니다 — 248 × 8 = 1,984, 즉 8타짜리가 된 겁니다.
방어 포함 버튼은 타수 공식을 (HP+방어)÷데미지와 HP÷데미지 사이에서 바꿉니다. 어느 쪽이 맞는지는 기록·분석 탭에서 실측과 대조하세요. 데미지를 비우면 전부 1타로 계산합니다.
배율은 승천·소울 리퍼·베스티어리 마스터리·장비 옵션이 다 곱해진 최종 배수입니다. 183 Spd처럼 단위째 넣어도 됩니다 — 모르면 1로 두고 차원끼리 상대 비교만 하거나, 기록·분석 탭에서 실측해서 자동으로 채우세요.

소울
스폰 한 자리를 놓고 소형 적들이 균등하게 나오고, 그중 거인 스폰%만큼이 거인입니다. 적마다 타수가 다르므로 단단한 적은 그만큼 덜 잡힙니다.
거인 소울과 거인 타수를 나란히 놨습니다 — 낮은 차원의 1타 거인과 높은 차원의 여러 타 거인 중 뭐가 나은지가 여기서 갈립니다. 소울이 10배라도 타수가 10배면 본전이고, 타수가 그보다 덜 늘면 이득입니다.
소울/초가 높은 차원이 오프라인으로 돌리기 좋은 곳입니다. 미니게임·포털 스테이지는 오프라인 진행이 없어 뺐습니다.
