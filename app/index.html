일정 위젯 앱

홈 화면에 오늘 일정과 할 일을 띄우는 안드로이드 위젯이에요. 일정 추가·수정은 위젯을 눌러 여는 일정 화면에서 해요.

플레이스토어로 설치했다면

업데이트는 플레이스토어에서만 해요 (앱 및 기기 관리 → 업데이트). 아래 APK 는 서명이 달라서 플레이스토어 앱 위에 설치되지 않아요.

플레이스토어를 쓰지 않는 경우에만:

APK 내려받기

처음 설치

  1. 위 버튼으로 내려받고, 다운로드 완료 알림(또는 내 파일 → 다운로드)에서 파일을 눌러요
  2. "이 출처의 앱 설치 허용"이 나오면 켜고 뒤로 돌아와 설치
  3. "확인되지 않은 앱" 경고가 뜨면 무시하고 설치 (플레이스토어 앱이 아니라서 떠요)
  4. 일정 위젯 앱을 열고 웹 일정과 같은 동기화 비밀번호로 연결
  5. 홈 화면 빈 곳 길게 누르기 → 위젯 → 일정 위젯 → 끌어다 놓기

위젯 종류 (홈 화면 → 위젯 → 일정 위젯)

  1. 일정 달력: 한 달 달력, ‹ › 로 달 이동, 날짜 누르면 그날 일정
  2. 일정 목록: 오늘·내일 일정 + 할 일
  3. 할 일 목록: 남은 할 일만 (중요·기한 지난 것 먼저)

크기는 놓은 뒤 위젯을 길게 눌러 테두리를 끌어서 바꿔요.

PC 바탕화면 위젯 (Windows 10/11)

바탕화면에 붙는 작은 창으로 오늘 일정·할 일을 보고 바로 추가해요. 폰과 같은 동기화 비밀번호를 쓰면 자동으로 같이 바뀌어요.

PC 위젯 내려받기 (zip)
  1. 압축을 풀어 폴더째 원하는 곳에 두고 SchedWidget.exe 실행 (Windows 보호 경고가 뜨면 "추가 정보 → 실행")
  2. 위젯의 ☁ 끔을 눌러 동기화 비밀번호 입력
  3. 작업 표시줄 오른쪽 아이콘 메뉴: 항상 위, 위치 잠금, Windows 시작 시 실행

업데이트

앱을 열었을 때 "새 버전이 있어요"가 보이면 이 페이지에서 다시 내려받아 설치하면 돼요. 연결과 위젯 자리는 그대로 남아요.
